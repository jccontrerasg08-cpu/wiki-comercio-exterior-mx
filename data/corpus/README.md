# Corpus RAG (`official-not-relicensed`)

Project-authored Markdown extracts for retrieval. **They do not replace** the DOF, SIDOF, or official PDFs. Quoted law is tagged official-not-relicensed; it is not Apache-2.0 just because it sits here.

Official URL catalog: `docs/catalog/`. Manifests + SHA-256: `data/originals/`. Bytes: GitHub Release `originals-YYYY.MM.DD`.

This corpus is not a commercial import course. No Incoterms® rule text. No WCO explanatory notes. Map: `docs/wiki/index.md`.

Base files:

- `operacion-comex-base.md`
- `fuentes-oficiales-comex-mx.md`
- `casos-tipo-comex.md`
- `requisitos-pais-ejemplo.csv`

RGCE 2026 summaries (anexos 1–30), Ley Aduanera, reglamento, TIGIE/NICO notes, NOMs: see the files in this folder.
