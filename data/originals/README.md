# Originales oficiales (manifiestos)

Git holds `MANIFEST.yaml` only: official URL, SHA-256, byte size, and
`license: official-not-relicensed`. PDFs, `.doc`, `.docx`, and `.xlsx` are
GitHub Release assets (`originals-YYYY.MM.DD`), not clone blobs.

Each folder has `MANIFEST.yaml`. Root `manifest.yaml` lists those fragments.
Binding cite is the official URL (SIDOF, Diputados, SAT). This project does
not re-license gazettes or treaties.

Incoterms® and WCO explanatory notes stay catalog-only (`docs/catalog/global/index.md`).
No ICC rule text here.

Resúmenes: `data/corpus/`.
