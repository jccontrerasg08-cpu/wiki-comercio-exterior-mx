# Activos visuales de la wiki

Los activos de este directorio se conservan sólo cuando su procedencia y función editorial están documentadas. No se incluyen capturas de trámites, imágenes de terceros sin licencia clara ni reproducciones de documentos jurídicos sólo para decoración.

| Archivo | Tipo | Procedencia | Uso editorial | Control |
|---|---|---|---|---|
| `snice-comercio-exterior-oficial.jpg` | Banner institucional | [Portal oficial SNICE](https://www.snice.gob.mx/cs/avi/snice/home.html), archivo visual `portada_final1.jpg` enlazado por el propio portal | Contextualiza la biblioteca de instrumentos y la capa de consulta del comercio exterior | SHA-256 `b935e4a0a69034dddbd12b81b2c5895095f48ce76237af7bae898547f091f165`; la leyenda debe aclarar que no acredita vigencia jurídica. |
| `fuentes-oficiales-comercio-exterior.mmd` | Fuente de diagrama | Elaboración propia | Define la relación funcional entre publicación, texto consolidado, herramientas y expediente | Mantener junto con el PNG para reproducción determinista. |
| `fuentes-oficiales-comercio-exterior.png` | Diagrama renderizado | Elaboración propia a partir del archivo Mermaid contiguo | Visualiza la arquitectura documental de la guía de RRNA | Renderizado con `manus-render-diagram`; no representa jerarquía entre autoridades. |

Antes de añadir un activo, confirma que resuelve una necesidad de lectura concreta, incorpora texto alternativo, se mantiene razonablemente liviano y cuenta con fuente o licencia verificable. La fuente visual no reemplaza las [fuentes jurídicas y operativas](../../catalog/index.md) del repositorio.
