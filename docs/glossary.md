# Glosario

| Término | Significado operativo |
|---|---|
| ANAM | Agencia Nacional de Aduanas de México, autoridad aduanera federal. |
| DTA | Derecho de Trámite Aduanero previsto en la Ley Federal de Derechos. |
| IGE / IGI | Impuesto General de Exportación / Importación determinado con la LIGIE. |
| IMMEX | Programa para importación temporal vinculada a manufactura, maquila o servicios de exportación. |
| NICO | Dos dígitos nacionales añadidos después de la fracción arancelaria de ocho dígitos. |
| NOM | Norma Oficial Mexicana. Su exigibilidad en punto de entrada depende del marco aplicable y de las reglas de la SE. |
| PROSEC | Programa de Promoción Sectorial con aranceles preferenciales para insumos autorizados. |
| RGCE | Reglas Generales de Comercio Exterior emitidas por SAT. |
| RRNA | Regulaciones y restricciones no arancelarias, como permisos, avisos, cupos o NOM. |
| SIDOF | Sistema de consulta del Diario Oficial de la Federación. |
| TIGIE | Tarifa contenida en el artículo 1 de la LIGIE. |
| VUCEM | Ventanilla Digital Mexicana de Comercio Exterior. |
