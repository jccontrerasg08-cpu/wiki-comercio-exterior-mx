# Mexico

Mexico is the deep archive. The repository preserves important primary legal documents and official datasets through document manifests and, when appropriate, GitHub Release bundles with SHA-256 verification. SIDOF, Cámara de Diputados, SAT and the competent issuing authority remain the legal or official reference for effect and currentness.

A portal and an archived original serve different purposes: interactive services may stay as live references, while downloadable primary documents or reproducible datasets can be preserved when that adds auditability or resilience.

## Interactive and reference portals

These entries are retained as live official interfaces. A portal is not automatically harvested merely because it is reachable; preservation or structured ingestion is decided source by source according to reproducibility, stability, format and evidentiary value.

- [T-MEC](https://www.gob.mx/t-mec) - `mx_gob_tmec`
- [ANAM](https://anam.gob.mx/) - `mx_gob_anam` (`gob.mx/anam` was unavailable at the last recorded source check).
- [SAT Padrón](https://www.sat.gob.mx/minisitio/PadronImportadoresExportadores/index.html) - `mx_sat_padron`
- [UPCI](https://www.gob.mx/se/acciones-y-programas/industria-y-comercio-unidad-de-practicas-comerciales-internacionales-upci) - `mx_gob_upci`
- [SNICE cuotas compensatorias](https://www.snice.gob.mx/cs/avi/snice/drrnas.cuotascomp.html) - `mx_snice_cuotas`
- [SNICE LIGIE](https://www.snice.gob.mx/cs/avi/snice/ligie.info22.html) - `mx_snice_ligie_info` (also on [Arancel TIGIE](arancel.md))
- [SNICE Mi Fracción](https://www.snice.gob.mx/cs/avi/snice/hce.mi.fraccion.arancelaria.html) - interactive/reference entry; use a verified structured source rather than treating the CMS shell as tariff evidence.
- [INEGI TIGIE–SCIAN app](https://www.inegi.org.mx/app/tigie/) - interactive classifier; preserve or ingest only through a documented reproducible source path.
