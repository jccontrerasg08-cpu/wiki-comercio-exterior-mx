# Catálogo de fuentes oficiales

México concentra el archivo documental profundo. Este repositorio preserva documentos jurídicos primarios y conjuntos operativos cuando una copia local o de release mejora materialmente la reproducibilidad, auditabilidad o resiliencia. Los originales grandes pueden residir en paquetes de GitHub Releases con checksums SHA-256, mientras los manifiestos por documento conservan la URL oficial, el hash y el tamaño en bytes.

La publicación oficial conserva la autoridad jurídica. La presencia en el archivo, una descarga correcta o una respuesta HTTP 200 nunca determinan por sí solas la vigencia jurídica.

Las tablas estructuradas TIGIE/NICO residen en [arancel-mx](https://github.com/jccontrerasg08-cpu/arancel-mx); esta wiki conserva la capa documental y de procedencia jurídica, no una base arancelaria competidora. Las fuentes propietarias, como Incoterms®, son sólo de referencia: no se incorpora el texto de reglas ICC.
