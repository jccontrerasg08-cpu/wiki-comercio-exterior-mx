# TLC y T-MEC

## Qué es

Un tratado de libre comercio baja o elimina aranceles entre partes si la mercancía cumple origen. El T-MEC (USMCA) es el acuerdo México–Estados Unidos–Canadá vigente.

## Cómo aplica en México

En el pedimento se invoca el trato preferencial y se acredita origen. Sin certificado o registro válido, se paga el arancel TIGIE general.
