# Security

This repository holds no credentials. Do not open a public issue for a vulnerability.

Report privately with GitHub's private vulnerability reporting on this repository.

Include the affected path or workflow, impact, reproduction steps, and a safe proof of concept. Do not include taxpayer records, credentials, cookies, or confidential customs documents.

Incorrect legal content, a stale URL, or a missing reform is a content-integrity issue rather than a security vulnerability. Report it with the catalog or wiki issue template unless disclosure would expose a security weakness.

Do not commit `.env`, `token.txt`, API keys, cookies, RFC portfolios, or personal data.

Supported version: the default branch (`main`).

Maintainers aim to acknowledge a private report within seven days. No bounty or response-time guarantee is offered.
